### Bug corrigido — `Extrair imagem com ia` (PainelSaúde, 3 workflows)

**Erro:** `Problem in node 'Extrair imagem com ia' — Text for item 0 is not defined`

**Causa:** O node `HTML Reconhecimento/Fonte` (extrator CSS) transforma o JSON da resposta do Jina.ai — após ele, `$json.data.content` é `undefined`. O node `Extrair imagem com ia` usava essa referência quebrada.

**Fluxo problemático:**
```
Scraper Jina.ai → HTML Reconhecimento/Fonte → Tem imagem em destaque?
                                                  └─[FALSE]→ Extrair imagem com ia
                                                             text={{ $json.data.content }}  ← UNDEFINED
```

**Fix aplicado** nos 3 workflows PainelSaúde:
```
text={{ $('Scraper Jina.ai Reconhecimento/Fonte').item.json.data.content
       || $('Scraper Jina.ai Reconhecimento/Fonte').item.json.data.html
       || '' }}
```
Referencia o node do Jina.ai diretamente (antes da transformação pelo HTML extractor), com fallback para `.data.html`.
